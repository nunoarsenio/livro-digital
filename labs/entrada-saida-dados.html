Como chegam os dados do disco à memória?

Os dispositivos são muito mais lentos do que o processador. É preciso trazer 6 bytes de um dispositivo para a RAM. Compara as três formas de o fazer e repara no que o processador (CPU) faz enquanto espera. Muda também o dispositivo: com um dispositivo rápido, as conclusões mudam.

As técnicas

E/S programada espera ativa

A CPU pergunta ao controlador, vezes sem conta, «já tens os dados?» (polling). Quando estão prontos, é ela que os copia byte a byte para a RAM.

Vantagem: é simples. Desvantagem: a CPU fica presa a esperar e não faz mais nada.

E/S por interrupções

A CPU pede os dados e vai trabalhar noutro programa. Quando um byte fica pronto, o controlador envia uma interrupção e a CPU pára um instante para o copiar.

Vantagem: a CPU não perde tempo à espera. Desvantagem: há uma interrupção por cada byte; com muitos dados, isso pesa.

DMA acesso direto à memória

A CPU diz ao controlador DMA o que copiar e para onde, e vai trabalhar. O DMA copia tudo sozinho para a RAM e só no fim envia uma interrupção.

Vantagem: a CPU quase não é incomodada; ideal para muitos dados (discos, placas de rede, gráficas). Desvantagem: precisa de hardware próprio.

Palavras-chave

  • Periférico: dispositivo de entrada (teclado, rato), de saída (monitor, impressora) ou de entrada e saída (disco, placa de rede).
  • Controlador: o circuito que comanda o dispositivo. Tem registos de estado, de comando e de dados.
  • Driver: o programa do SO que sabe falar com um controlador.
  • Barramento: as ligações por onde os dados circulam entre a CPU, a RAM e os controladores.

O que acontece numa interrupção

Uma interrupção é um sinal que um dispositivo envia à CPU a dizer «preciso de atenção». A CPU pára o que está a fazer, trata do assunto e depois continua exatamente onde estava, sem o programa dar por nada.

Palavras-chave

  • Pedido de interrupção (IRQ): o sinal elétrico que o dispositivo envia. Cada dispositivo tem o seu número.
  • Contexto: o estado do programa interrompido (o contador de programa e os registos). Tem de ser guardado para depois continuar.
  • Tabela de vetores: diz, para cada número de interrupção, onde está a rotina que a trata.
  • Rotina de tratamento (ISR): o código do núcleo que trata a interrupção. Deve ser curta e rápida.
  • A interrupção do relógio é a que permite ao SO tirar a CPU a um processo quando acaba o seu quantum.

Buffers: porque é que o vídeo «está a carregar»

Um buffer (memória intermédia) guarda dados temporariamente entre quem os produz e quem os consome, quando trabalham a velocidades diferentes. Num vídeo, a rede entrega os dados aos solavancos, mas o leitor precisa de 1 segundo de vídeo por cada segundo. Experimenta vários tamanhos de buffer.

Buffers no sistema operativo

  • Teclado: as teclas ficam num buffer até o programa as ler. Por isso não se perdem se o programa estiver ocupado.
  • Impressora: os documentos ficam numa fila no disco (spool) e o programa pode continuar a trabalhar.
  • Disco: o SO guarda em memória os blocos usados há pouco (cache), para não ter de os ler outra vez.
  • Duplo buffer: enquanto um buffer está a ser enchido, o outro está a ser lido. É assim que os jogos desenham o ecrã sem tremer.

Um buffer maior aguenta melhor as falhas da rede, mas gasta mais memória e o vídeo demora mais a começar.

Para onde vai a cabeça do disco?

Num disco rígido, a cabeça de leitura tem de se deslocar até ao cilindro (pista) certo, e esse movimento é lento. Quando há vários pedidos à espera, o SO escolhe a ordem de atendimento para a cabeça andar o menos possível. Os cilindros vão de 0 a 199.

Os algoritmos

FCFS pela ordem de chegada

Atende os pedidos pela ordem em que chegaram.

Vantagem: é justo e simples. Desvantagem: a cabeça anda para trás e para a frente, e o movimento total é grande.

SSTF o mais próximo primeiro

Atende sempre o pedido mais perto da posição atual da cabeça.

Vantagem: reduz muito o movimento. Desvantagem: um pedido longe pode esperar indefinidamente se continuarem a chegar pedidos perto (míngua).

SCAN algoritmo do elevador

A cabeça vai num sentido até ao fim do disco, atendendo os pedidos pelo caminho, e depois inverte o sentido, como um elevador.

Vantagem: nenhum pedido fica esquecido. Desvantagem: os pedidos nas pontas esperam mais.

C-SCAN elevador circular

Atende os pedidos só num sentido. Quando chega ao fim, volta ao início sem atender ninguém (linha tracejada) e recomeça.

Vantagem: o tempo de espera é mais uniforme para todos os pedidos. Desvantagem: o regresso ao início também gasta movimento.

Palavras-chave

  • Tempo de procura (seek time): o tempo que a cabeça demora a chegar ao cilindro certo. É a maior parte do tempo de acesso.
  • Nos SSD não há partes móveis, por isso estes algoritmos quase não fazem diferença.
